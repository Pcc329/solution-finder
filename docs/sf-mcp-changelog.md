# SF MCP 變更紀錄

## v1.4.0

- **破壞性變更**。搜尋清單以 `price_range` 取代精確 `price`。`search_solutions` 以 `monthly_price_range` 取代精確 `monthly_price`。`search_companies` 提供總費用級距，月費可用 `get_solutions` 查詢。兩個詳情工具保留精確價格。
- **破壞性變更**。`search_companies` 的每頁上限由 50 家改為 10 家，預設值由 20 家改為 10 家。搜尋方案與廠商的 offset 上限分別為 200 筆與 100 家。
- 啟用每帳號每分鐘 30 次呼叫的限流。方案明細的每日額度預設為 300 筆，可逐帳號設為 1～5000 筆，依臺北時間每日 00:00 重置。
- 記錄每帳號每日逐工具的呼叫次數與回傳明細數。`whoami` 顯示當日明細用量與額度。白名單可標示真人或 Agent 帳號。

## v1.3.1

- `describe_data` 補充大量匯出限制及盤點指引。
- 新增財會關鍵字對照。以「財務」及「會計」分別搜尋，依方案 ID 取聯集。
